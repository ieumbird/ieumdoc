# 48 V 전력 변환기의 전류 제어 설계

이 설계 노트는 실험실 벅 변환기의 **전류 루프 기준 설계**를 다룬다. 수치는 설명을 위한 설계 입력이며 실측 결과나 승인된 하드웨어 설계가 아니다. 샘플 사본을 직접 편집할 수 있으며, 그림과 참고문헌은 문서 폴더와 함께 옮긴다.

(sec-requirements)=

## 설계 조건

변환기는 공칭 $48\,\mathrm{V}$ 직류 전원으로 저항 부하를 구동한다. 20 kHz 제어 주기에서 샘플링 지연을 고려할 여유를 두기 위해 *목표 대역폭을 500 Hz*로 정한다. 전압 지령은 PWM 정규화 전의 전압 단위로 표현하므로 `kp`의 단위는 V/A다.

:::{table} 전류 루프 계산에 사용하는 공칭 입력
:name: tbl-ratings

| 항목       | 기호                |    공칭값 |
| -------- | ----------------- | -----: |
| 직류 입력 전압 | $V_{\mathrm{dc}}$ |   48 V |
| 필터 인덕턴스  | $L$               |   2 mH |
| 직렬 저항    | $R$               | 0.10 Ω |
| 제어 주파수   | $f_s$             | 20 kHz |
| 목표 대역폭   | $f_c$             | 500 Hz |
:::

{numref}`tbl-ratings`의 값은 하나의 공칭 운전점을 정의한다. 평균화 변환기 모델을 출발점으로 삼되 {cite:p}`erickson2020`, 아래의 단순화된 조정식은 이 노트에서 직접 유도한다. 서지 정보는 [출판사 도서 안내](https://link.springer.com/book/10.1007/978-3-030-43881-4)에서 확인할 수 있다.

*   전압 지령은 사용 가능한 듀티비 범위 안에 둔다.
*   공칭 모델이 성립하지 않는 조건을 기록한다.

    *   인덕턴스는 전류와 온도에 따라 달라진다.
    *   ADC 필터와 연산은 지연을 추가한다.
*   해석 예측과 이후의 실측 결과를 구분한다.

(sec-model)=

## 플랜트와 제어 법칙

미소 전류 변화에 대해 부하 측 전압을 외란으로 두고, 전압 지령에서 전류까지의 플랜트를 $G(s)=1/(Ls+R)$로 근사한다. 이 모델은 스위칭 리플, 포화, 지연을 제외한다.[^model]

:::{figure} ./assets/current-loop.svg
:name: fig-loop
:alt: 전류 지령과 측정값의 차이가 PI 제어기로 들어가고, 제한된 전압 지령이 RL 플랜트를 구동하며 측정 전류가 되먹임된다.

PWM 정규화 전의 물리적 전압 단위로 표현한 전류 루프.
:::

이 이상화 모델에서는 PI 영점으로 공칭 플랜트의 극점을 상쇄한다. $\omega_c=2\pi f_c$일 때 다음과 같이 정하면 개루프는 $\omega_c/s$가 된다.

```{math}
:label: eq-gains

K_p=L\omega_c,\qquad K_i=R\omega_c.
```

{eq}`eq-gains`에 {numref}`tbl-ratings`의 값을 대입하면 $K_p\approx6.28$, $K_i\approx314.16$이다. 연속 시간 계수이므로 소프트웨어에서는 적분항에 샘플 주기를 곱한다. 공칭 극점 상쇄만으로 실제 지연을 포함한 플랜트의 안정성을 입증할 수는 없다.

> 계산한 대역폭은 조정 목표다. 실제로 달성한 대역폭은 측정한 루프 응답으로 확인해야 한다.

:::{warning}
극성과 센서 배율을 확인할 때는 전력단을 비활성화한다. {numref}`fig-loop`의 되먹임 부호가 반대이면 양의 되먹임이 형성된다.
:::

### 이산 구현

샘플 주기가 $T_s=50\,\mu\mathrm{s}$일 때 아래 의사 코드는 후보 지령이 포화 범위를 벗어나면 적분을 멈춘다. 통전 시험 전에 별도의 기동 램프와 하드웨어 보호가 필요하다.

```python
error = reference - measured_current
candidate = integral + ki * sample_period * error
voltage = kp * error + candidate
if 0.0 <= voltage <= dc_voltage:
    integral = candidate
command = min(dc_voltage, max(0.0, voltage))
```

## 검증 순서

{numref}`fig-sequence`의 흐름은 {ref}`sec-requirements`의 사전 점검과 통전 시험을 구분한다. 응답을 해석하기 전에 {ref}`sec-model`의 모델 가정을 확인한다.

:::{figure}
:name: fig-sequence

```{mermaid}
flowchart LR
  A[전력단 비활성화] --> B[센서와 극성 확인]
  B --> C[저전류 시험]
  C --> D[계단 응답 기록]
```

제안하는 실험 순서이며 시험 결과를 뜻하지 않는다.
:::

1.  전력단을 비활성화한 상태에서 센서 영점을 확인한다.
2.  전류 제한 전원과 낮은 전류 지령을 사용한다.

    1.  양의 오차가 전압 지령을 높이는지 확인한다.
    2.  포화 중 적분 상태가 누적되지 않는지 확인한다.
3.  전류 계단 응답을 버스 전압 및 부하 조건과 함께 기록한다.
4.  측정 응답과 공칭 목표를 비교하고, 재조정 전에 모델을 수정한다.

:::{note}
비교 시험에서는 샘플링 주파수, 센서 필터, PWM 갱신 시점을 동일하게 유지한다. 원시 계측 자료는 해당 설계 개정본과 함께 보관한다.
:::

## 검토 결론

공칭 계수는 시뮬레이션 검토에 사용할 수 있다. 지연, 부품 편차, 전류 제한을 확인할 때까지 하드웨어 승인은 보류한다. 다음 개정에서는 설계 가정을 조건 없는 성능 주장으로 바꾸지 않고, {ref}`sec-verification`에 실측 근거를 첨부한다.

[^model]: 이 예제의 RL 근사는 인덕터 전류의 미소 변화 경로를 설명한다. 출력 커패시터를 모델링하거나 외부 전압 루프를 닫는 모델은 아니다.
