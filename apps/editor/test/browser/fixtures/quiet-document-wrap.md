# 한국어 기술 문서의 줄바꿈 검토

전력변환 시스템은 입력전압을 측정하여 컨버터로 전달하고 제어기는 출력전류의 오차를 계산한다. 측정결과를 정리한다. 「제어설계」에서는 안정성과 응답속도를 함께 검토한다. (전압제어), 전류제어 및 보호기능을 확인한다.
