## Release notes draft

This Beta improves Windows release and update reliability. Stable checks now explain when no Stable release has been published. Beta updates remain available, and switching channels never downgrades the installed app. Downloads and installation still require the user's request, and unsaved documents prevent an update restart.

Maintainers can build and verify a release without publishing, publish a verified unsigned Beta, or publish with Authenticode signing. Existing releases and assets are never overwritten. Tags must belong to trusted master history; executable versions, metadata, blockmaps and uploaded asset hashes are checked before activation.

This installer is unsigned. Windows may display unknown-publisher or SmartScreen warnings. Checksums verify file integrity, not publisher identity. Document semantics, application identity, saved preferences and document locations are unchanged.

## Failure boundaries

| Risk | Defense and evidence |
| --- | --- |
| Unsigned Stable, malformed tag or unknown mode | Preflight rejects before tag code/dependencies; release mode tests |
| Missing/off-master/version-mismatched/moved tag | Trusted dispatch SHA, git ancestry, immutable build SHA and remote peel comparison before activation; isolated Git fixture tests |
| Existing Release/Draft, including later pages | Authenticated pagination, refuse all collisions; Draft page-2 test; no clobber/delete path |
| Partial upload, wrong asset set/state/hash | New Draft ID, exact three assets and uploaded-state/size/server SHA-256 gate; failure tests never activate |
| Wrong manifest or installer/blockmap | Existing YAML parser, SHA-512/size/version/name checks, builder recomputation, PE versions; negative metadata/chunk/checksum tests |
| Network failure versus absent Stable | Exact endpoint with structured status and valid Beta-only evidence; feed/metadata/503 faults remain errors; real archive-tag feed and 406 tested |
| Channel switch during an async check | Existing generation guard and queued recheck; real updater race test and no-downgrade tests |
| Ordinary quit or unsaved update restart | No auto-download/quit-install; live Editor veto, IPC timeout/failure and Save gate; real NSIS mock-feed tests |
| Lost publication response | Release ID and confirmation-required error; no automatic retry or false unpublished claim; activation transport-failure test |
| Premature publication claim | README continues to name public beta.1; beta.2 and actual GitHub update remain Pending |

The fixture now uses a prepared repository scratch directory and exact OS-native path matching; the expected 404 checks and production Host are unchanged. No beta.2 Release was created by that failed run.

The next [publication run](https://github.com/ieumbird/ieumdoc/actions/runs/38200456526) passed the corrected open-files fixture but stopped before publication on Equation Escape focus and first-Saved unload observations (41/43 browser tests passed). The unchanged focused tests passed locally. Their assertions now wait for the exact expected focus/selection and observe only the held Save's first Saved commit; they neither set focus nor retry unload until it succeeds. Production code and the success conditions are unchanged. Browser diagnostics are retained on workflow failure. No beta.2 Release was created by this run either.

Independent lifecycle review then found that Equation's pending autofocus frame could run after Cancel while BaseUI retained the closing textarea, taking focus away from the editor before unmount. Apply, Cancel, a new Edit and unmount now cancel that pending frame without changing insertion timing. The focused Equation/update scenarios and Editor typecheck passed locally. Observation waits have explicit 30-second limits so a failed focus or unload observation cannot consume the full scenario timeout.

The [preceding Windows run](https://github.com/ieumbird/ieumdoc/actions/runs/38201911416) was cancelled after its browser step stalled. Recovered logs showed `ERR_NO_BUFFER_SPACE` in Vite WebSocket/module requests: 40 browser tests passed (including Equation), two failed and Desktop updates was interrupted. The full browser suite now runs on Linux, the existing PR/push browser CI platform, while actual Electron/NSIS packaged and Stable/Beta install/update tests remain on Windows. Publication requires both jobs to pass. This run created no Release; publication and public-update acceptance remain Pending.
