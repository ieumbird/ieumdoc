## Release notes

**Breaking and behavior changes**

- References without a custom template now follow MyST defaults: **Figure 1**, **Table 1** and **(1)**, replacing the earlier **Fig. 1** and **Eq. (1)** presentation. Choose a Reference style in Display to customize the wording; it is saved in the document.
- **Tab in the last table cell adds a row** and moves to its first cell. Undo removes the added row.
- A leading H1 is now the document title and stays first when moving or inserting content. Its Markdown format is unchanged.
- Beta.4 native documents still open; `ieumdoc: 1` remains the format marker. Invalid Unicode or UTF-8 is now rejected instead of silently replaced during saving. New citations and reference-template metadata require this version. Unmarked documents from beta.3 or earlier remain rejected; no automatic migration or marker insertion is provided.

**Editor**

- Insert and edit citations, search BibTeX entries and display a numbered References list. Connect or disconnect a document's neighboring `.bib` files in the Editor, then Save to apply the connection. Bibliography files are never modified.
- Switch between Korean and English in Settings without losing edits, selection or Undo history.
- Open multiple folders, collapse their sections and remember their order and collapsed state. Browse all file types and preview images without leaving the document.
- Keep independent documents in tabs and restore their order and active tab after restarting. Local recovery offers unsaved work after an interruption; Save / Don't save / Cancel protects work when closing a tab.
- Search commands, open tabs and listed folder documents in the command center (**Ctrl/⌘+/**). Insert citations or cross-references at the caret from the center; open the link form with **Ctrl/⌘+'**.
- Find references by caption or displayed number, keep references attached when renaming labels, and see a warning before deleting a referenced target. Display offers Default, Concise, Formal and Korean reference styles.
- Editing is more responsive in large documents. Typing after equations, continuing below the final block and undoing Figure deletion are more reliable.

**CLI**

- Preview edits and batches with `--dry-run`; insert at the body end with `--at end`, including equation labels and table captions/labels.
- Manage citations, bibliography declarations and reference templates; opt in to updating references when renaming a label. `check` reports missing Figure images, undefined footnotes and reference/code syntax written as literal text.

**Desktop**

- Includes the new Editor, remembered folders/tabs and local unsaved-work recovery. Recovery keeps the last successful local record; it does not save the original file automatically.
- The Windows x64 installer remains unsigned; Windows may show unknown-publisher or SmartScreen warnings. Stable remains unpublished.

## Known reports and limitations

- Very fast Enter immediately after a click or End can split at the previous caret position ([#416](https://github.com/ieumbird/ieumdoc/issues/416)); this was reproduced with automated input, not a physical keyboard.
- Original-file autosave is not available; save explicitly even when local recovery is enabled ([#297](https://github.com/ieumbird/ieumdoc/issues/297)).
- On Windows, manually entering the same folder path with different letter case can produce duplicate navigation entries ([#372](https://github.com/ieumbird/ieumdoc/issues/372)).
- Bibliography formatting is a limited IEEE-style subset; CSL style selection, locators, automatic author rendering and editing `.bib` files are not provided ([citation contract](../design/citations-v1.md)).
- The installer is unsigned, and Stable is unpublished. Checksums establish integrity, not publisher identity.
