## Release notes

**Breaking: IeumDoc native documents only**

- IeumDoc now opens and saves only native documents: `.md` files whose leading YAML frontmatter contains `ieumdoc: 1` and whose body uses only supported content. **Documents created by beta.3 or earlier do not have this marker and will not open.** No migration or automatic marker insertion is provided, and adding the marker alone does not make unsupported content valid.
- Create documents with **New file** (or `ieumdoc create <file>`). Partial editing of general Markdown, read-only opening of unsupported files and Edit source have been removed. Whole-document Source remains an applied-content preview.
- Opening an unsupported file now shows a dialog naming the file, the reason and what to do. The current document stays unchanged.
- Desktop provides a new native sample in `sample-native-v1`. Existing `sample` folders and your copies are not overwritten.

**Editor**

- Paste or drop an image onto an empty Figure to fill that Figure, keeping its label and caption. Figures that already have an image still get a new Figure after them.
- Choose a Figure image from your computer with **Choose…**. Images outside the document's folder are copied into `assets/`.
- Relative image paths without `./` (for example `assets/diagram.svg`) now display.
- The document page is visually distinct from the background, and hovering a block outlines its extent.
- Long folder names in the sidebar are shown in full, with Korean words kept together.
- Save failures explain where the problem is and what to do next.

**CLI**

- `inspect --format json` reports a `revision`. Every edit command accepts `--if-revision` and refuses to write if the file changed since that inspect.
- `apply-batch` applies many edits from a JSON file in order and writes the file once. If any step fails, nothing is written.
- Addressing block 0 (the document metadata) now explains that body blocks start at 1.

The installer remains unsigned; Windows may show unknown-publisher or SmartScreen warnings. Stable remains unpublished.

## Known reports and limitations

- Documents from beta.3 or earlier, and Markdown not created by IeumDoc, cannot be opened (see above).
- Citations and bibliographies are not supported; a document containing `{cite}` is rejected ([#265](https://github.com/ieumbird/ieumdoc/issues/265)).
- The Editor UI is English only ([#256](https://github.com/ieumbird/ieumdoc/issues/256)).
- The sidebar lists only `.md` files ([#217](https://github.com/ieumbird/ieumdoc/issues/217)).
