## Scope and completion

The user authorized versioning and publication as `0.0.1-beta.3`. This release packages the changes already merged into master since beta.2. Only the Desktop version, existing Beta update regression versions and release documentation change here. No new features or unrelated fixes are included.

Completion requires required PR/master CI, an immutable master tag, the manual unsigned-beta workflow (full browser, Windows workspace, Stable/Beta NSIS update, clean package and packaged checks), approved environment publication, verified public assets and real GitHub beta.2→beta.3 update. Public-version documentation changes only after confirmed publication. Test-owned processes and installation/data are cleaned up; existing user installations are protected.

## Release notes

- Start without automatically opening a sample; choose a folder and navigate documents from Files, including creating folders.
- Files and Display tools are organized separately, with document width and heading numbering controls.
- Improved writing space, outline tracking and heading-level changes with Tab.
- Footnote definitions appear in one endnotes region and are normalized after the body on write.
- Empty Figures can be saved as placeholders.
- A production HTTP Host can serve the Editor within explicitly allowed roots; file-access boundaries were hardened.
- Windows now uses the dedicated IeumDoc icon.

The installer remains unsigned; Windows may show unknown-publisher or SmartScreen warnings. Stable remains unpublished.

## Known reports and limitations

- [#210](https://github.com/ieumbird/ieumdoc/issues/210): read-only paragraph replacement on typing was reported, but its exact input/environment and reproduction remain unconfirmed. Existing adapter, transaction and save guards reject read-only changes; passing those regressions does not resolve this report.
- [#211](https://github.com/ieumbird/ieumdoc/issues/211): relative Figure paths without `./` may not display.
- [#212](https://github.com/ieumbird/ieumdoc/issues/212): image paste inserts a new Figure rather than filling an existing empty Figure.
- [#217](https://github.com/ieumbird/ieumdoc/issues/217) and [#218](https://github.com/ieumbird/ieumdoc/issues/218): showing all file types/image previews and improving long folder-name visibility remain future improvements.
