# IeumDoc v0.0.2-beta.2 — 공개 전 준비·검증 기록

- Status: Draft
- Last verified: 2026-10-28 (이슈와 병합 PR 대조, Desktop typecheck·67개 단위 테스트, 설치 없는 로컬 후보 package·자산 검증 통과. 공개 전 후보이며 배포·공개 자산·실제 GitHub 업데이트 검증 결과가 아님).
- Scope: [#659](https://github.com/ieumbird/ieumdoc/issues/659)의 Windows x64 unsigned Beta 준비 PR. 현재 공개 버전은 [v0.0.2-beta.1](v0.0.2-beta.1.md)이다.

## 준비 단계 작업 계획

- 범위: Desktop 후보 버전을 `0.0.2-beta.2`로 올리고 실제 GitHub 업데이트 harness의 향후 대상을 `0.0.2-beta.1 → 0.0.2-beta.2`로 맞춘다. 공개 버전과 후보를 구분해 문서·색인 및 한국어 Release 본문 초안을 준비한다.
- 제외: 기능 코드 변경, tag 생성, release workflow 실행·게시, 병합과 로컬 설치·앱 실행. 실제 GitHub 업데이트는 소유자 결정으로 이번 릴리스에서 실행하지 않는다. 리뷰 agent·하위 agent를 사용하지 않는다.
- 완료: 대상 로컬 검사와 준비 PR의 필수 CI가 통과하고 `Refs #659` PR을 오케스트레이터에 전달한다. 공개 후 기록과 이슈 종료는 오케스트레이터가 수행한다.
- 검증: frozen install, 문서·공백 검사, Desktop typecheck·단위 테스트와 가능하면 설치 없는 로컬 package·자산 검증. Stable·Beta local-feed 설치/업데이트, packaged·uninstall 검사는 disposable Windows CI에 맡긴다.

CI local-feed fixture는 Stable `0.0.1 → 0.0.2`, Beta `0.1.0-beta.1 → 0.1.0-beta.2`를 유지한다. 직전 준비 [PR #633](https://github.com/ieumbird/ieumdoc/pull/633)처럼 공개 버전과 독립적인 테스트용 버전 쌍이다. harness는 현재 소스를 `IEUMDOC_TEST_VERSION`과 local-feed host로 각각 빌드하므로 과거 공개 자산을 쓰지 않는다. 실제 GitHub `LIVE` 경로만 공개 버전 쌍을 사용한다.

## 공개 자산

공개 전이므로 아래 크기·해시와 installer SHA-512는 공개 다운로드 대조 후 채운다. 로컬 후보나 이전 버전의 해시를 공개 근거로 쓰지 않는다.

| 파일 | 크기 (bytes) | SHA-256 |
| --- | --- | --- |
| `beta.yml` | 게시 후 기록 | 게시 후 기록 |
| `IeumDoc-Setup-0.0.2-beta.2.exe` | 게시 후 기록 | 게시 후 기록 |
| `IeumDoc-Setup-0.0.2-beta.2.exe.blockmap` | 게시 후 기록 | 게시 후 기록 |

Installer SHA-512와 `beta.yml`의 version/path/files/hash/size 대조: 게시 후 기록.

## 알려진 제한

- unsigned Beta이며 Authenticode 게시자 인증을 제공하지 않는다. 체크섬은 무결성 검증이며 SmartScreen·조직 보안 정책 경고가 나타날 수 있다. Stable은 미공개다.
- 개발 단계이므로 이전 이음독 문서·복구 기록·설정의 하위 호환성과 자동 migration을 보장하지 않는다.
- 실제 GitHub `0.0.2-beta.1 → 0.0.2-beta.2` 설치·업데이트는 미검증이다. [실제 GitHub 검증 절차](../test/README.md#real-github-beta-update)와 CI local-feed 결과를 구별한다.
- 실제 Windows 창의 drag·더블클릭 최대화, 한글 IME 수식 입력, Desktop CLI 켜기/끄기는 별도 수동 확인 항목이다. 자동화·CI 성공으로 실제 사용자 환경 수용성을 판정하지 않는다. [수동 확인 경계](../test/README.md#manual-review)를 따른다.

## Release 본문 초안 (한국어)

아래는 공개 후 오케스트레이터가 Release에 반영할 본문 초안이다. 이 문서가 Release 게시 완료를 뜻하지 않는다.

> IeumDoc v0.0.2-beta.2는 Windows x64용 unsigned Beta입니다.
>
> **주요 변경**
>
> - 라이트 테마 + 페이지 모양 '평면'에서 창이 뜨지 않던 버그를 수정하고, 시작 실패 시 숨은 프로세스만 남지 않도록 창 표시·오류 안내를 보완했습니다. (#643)
> - 블록 수식을 문서 안의 넓은 입력면에서 미리보기와 함께 편집하며, 인라인 수식 입력 공간도 넓혔습니다. (#637)
> - 코드블록 언어를 드롭다운으로 선택합니다. (#645)
> - 블록 선택·호버 테두리를 맞추고 입력 중 호버 숨김을 보완했습니다. (#469)
> - 로고와 IEUMDOC 제목 띠를 추가하고 사이드바 머리를 문서 탭 높이에 맞췄습니다. (#647)
> - 붙여넣은 일반 이미지 이름에 문서 이름·순번을 사용하고, 그림 속성에서 로컬 이미지 이름과 참조를 함께 바꿀 수 있습니다. 드롭한 이름과 구체적인 원래 이름은 정리해 유지합니다. (#652)
> - Mermaid 다이어그램을 문서 안에서 작성·미리보기하고 그림 번호·캡션·상호참조로 사용할 수 있습니다. 외부 서비스 없이 앱 안에서 렌더링합니다. (#651)
>
> **설치와 주의 사항**
>
> Assets의 `IeumDoc-Setup-0.0.2-beta.2.exe`를 사용합니다. 별도 Node.js·pnpm이 필요하지 않습니다. 코드 서명되지 않은 Beta이므로 Windows SmartScreen 또는 조직 보안 정책 경고가 나타날 수 있습니다. 체크섬은 파일 무결성 확인용이며 게시자 인증을 대신하지 않습니다.
>
> 개발 단계이므로 이전 이음독 문서·복구 기록·설정의 하위 호환성을 보장하지 않으며 자동 migration을 제공하지 않습니다. 중요한 문서는 별도로 백업해 주세요.
>
> 실제 GitHub `0.0.2-beta.1 → 0.0.2-beta.2` 업데이트는 이번에 실행하지 않았으며 미검증입니다. CI local-feed 업데이트 결과와 구별합니다. 실제 Windows 창 drag·더블클릭 최대화, 한글 IME 수식 입력, Desktop CLI 켜기/끄기는 별도 수동 확인 항목입니다. 자세한 배포·검증 결과는 [릴리스 기록](https://github.com/ieumbird/ieumdoc/blob/master/docs/releases/v0.0.2-beta.2.md)을 참고하세요.
